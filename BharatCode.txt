While tools like Copilot explain what code does today, Archaeologist CLI uncovers why it exists. It is an autonomous forensic code intelligence engine and native Model Context Protocol (MCP) server built directly for your terminal. Instead of treating codebases as flat snapshots, Archaeologist reconstructs their living history into a temporal causal graph—connecting AST symbol lineages, git commit diffs, PR debates, issue discussions, and bidirectional revert chains.

Powered by a two-tier hybrid architecture uniting SQLite recursive CTEs with Rust-accelerated graph algorithms, it achieves zero-cost structural ingestion without expensive LLM indexing calls. It combines isolated 4-channel RRF retrieval, JIT diff expansion, and deterministic verification to eradicate hallucinations while auditing high-churn hotspots, temporal coupling, and bus-factor risks. It transforms murky legacy repositories into transparent, verifiable forensic truth.
